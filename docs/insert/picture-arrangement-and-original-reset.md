# 图片排列与还原原图

## 排列参照与等尺寸

图片工具栏和多选悬浮栏共享“所选对象范围 / 最后选中对象”参照。切换参照只改变界面状态，不修改工作簿；旧选区回调不会操作新选区。对齐使用实际未旋转布局框，组合使用自身框，不把内部叶图视觉并集作为组合尺寸。

等高、等宽、等尺寸始终采用最后选中的实际对象，与对齐参照无关。等高和等宽遵守每个对象自己的比例锁；等尺寸直接匹配双轴，并保留原比例锁。各对象的未旋转布局左上角保持不变，整批原子提交，一次撤销恢复整个选区。旋转对象固定未旋转布局左上角是 Sheetcraft 的明确扩展；桌面等尺寸测量覆盖零旋转对象。

“对齐网格”将移动或随单元格缩放的对象吸附到已有锚定单元格左上角；固定位置对象吸附到当前所在单元格左上角。它是一次操作，不是永久拖动吸附开关。尺寸、角度、裁剪、源图和组合保留；固定对象原点超出当前表格几何时明确拒绝，不静默钳位。

## 还原原图与独立重设入口

“还原原图”使用已读取的实际源图尺寸，保持当前未旋转布局框中心，清除裁剪、形状裁剪、二维旋转和翻转；保留外观、效果、标注、替代文本、保护、打印属性和身份。组合内真实图片可独立还原，兄弟成员和祖先框保留；组合容器没有原始图片尺寸。尚未读取尺寸或源不可用时，按钮禁用并给出原因。超出对象尺寸预算时按既有比例适配规则调整，不把当前框尺寸猜作原始尺寸。旧对象或旧源回调不会修改新选中对象，一次撤销/重做保留完整几何。

这是 Sheetcraft 既有合并操作的扩展，不作为已测得的 WPS 独立重设行为。其他入口各有自己的作用范围：

- 重设尺寸：按实际源图尺寸重建源图和框、清二维角度，保留布局位置和翻转。
- 重设图片：清外观和形状裁剪，不重设源图裁剪参数或角度。
- 重设裁剪：扩展到当前已缩放源图、清偏移和形状，保留缩放、角度及外观。
