# 符号

当前实现提供桌面式符号、特殊字符和自定义符号三个页面。视觉和交互细节仍待用户验收；历史代表性路径不等于完整工具验收。

## 字符选择

- Unicode 17 字符目录、346 个子集及中文子集名称。子集默认跳转完整字体字符列表，搜索可按字符、名称、码点或子集名称定位。
- 四款随产品提供的开放字体按真实 `cmap` 展示收录字符，字体和目录按需加载，网格使用窗口化呈现。源版本、哈希与 OFL 许可见[字体资源声明](../../apps/web/src/shared/cell-text/fonts/NOTICE.txt)及[Unicode 资源声明](../../apps/web/src/modules/insert-tools/symbols/assets/NOTICE.txt)。
- “普通文本”使用目标单元格的实际字体。覆盖尚未核验时明确说明，不将另一字体冒充为该字体；“全部 Unicode”浏览模式明确提示字形覆盖不保证。
- Unicode 十六进制和 Latin-1 十进制/十六进制输入。无效、代理区或当前模式不可用的代码不插入先前选中的字符。
- 特殊字符包括破折号、空格、版权、商标、节号、段落号、省略号和引号。全角空格 U+3000、普通空格 U+0020、标准 Em/En 空格 U+2003/U+2002 使用准确名称；不复制参考版本的错名。

## 连续插入与管理

- 插入按钮、字符双击和键盘确认均支持连续插入，关闭窗口后仍保持单元格编辑草稿，提交由单元格编辑器完成。
- 明确字体只作用于插入字符，原有文字字体保留；随后键入恢复插入前的字体上下文。公式编辑继续使用公式字符语义，不生成字符字体区间。
- 最近使用按文字和字体区分，产品上限为 18 项。明确关闭发布本次记录；Escape 关闭保留编辑草稿但不发布本次最近使用。这是产品定义，不表示参考应用的存储上限。
- 自定义符号提供 39 个准确默认值，支持添加、排序、删除、重置确认、菜单可见性及快捷键。可见性仅控制菜单；隐藏项的有效快捷键仍可使用。
- 快捷键检测冲突和保留组合，仅在允许插入的工作簿编辑上下文生效；自定义文本最多 16 个 Unicode 字符、自定义条目最多 256 项。

## 本机字体与数据

读取本机字体和打开字体文件均由用户主动操作。Local Font Access 不可用或授权被拒时，开放字体和文件选择仍可使用；不自动读取系统字体。

字体文件只留本机，默认仅本次会话使用；用户可主动选择保存到当前设备。支持经结构、名称和真实 Unicode `cmap` 验证的独立 TTF/OTF，单文件最多 64 MiB；TTC/WOFF、传统 Symbol 编码及无法验证的字库明确拒绝。设备字体缓存最多 12 款、合计 128 MiB。不同文件使用独立资产身份，不凭同名认定相同字库；跨设备仍需相应字体。

单元格值仍是普通字符串，字符字体区间使用 UTF-16 标量边界。编辑、复制、查找替换、填充、格式、保护和撤销重做保留相应合同；含区间的内部快照使用版本 46，无区间保持原 43/44/45 版本，旧快照可读。缺失字体会提示并保留原值与字体信息。

普通拉丁文字和符号使用分段 Canvas 排版。复杂多字体 RTL 使用安全文本节点的原生排版层；原生换行、垂直对齐和旋转包围盒不承诺桌面像素等价。当前照相机/打印的纯 Canvas 路径保留完整文本，但该复杂组合退回单元格字体，不保留各字符字形字体。不能可靠映射字符字体的自定义显示格式会提示，原始信息仍保留。

本能力不表示 XLSX 字符字体交换已实现。文件 I/O 与跨应用交换工作仍暂停。
