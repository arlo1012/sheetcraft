# 图片工具当前可用范围

## 常用入口

本地插入支持浮动图片和单元格图片。替换、压缩、原图标注、裁剪、预览和另存已有的 PNG/JPEG/WebP 路径消费真实源图及当前非破坏几何。浮动图片与组合内真实叶图的右键菜单汇集替换、裁剪、标注、预览、另存 PNG 和格式侧栏；组合容器不显示伪造的源图操作。另存更多现有格式仍可从图片工具栏选择。

单元格嵌入保留可编辑源和本地几何；非空单/多目标有明确覆盖确认。源与目标分别核验权限，旧确认、旧文件加载或旧菜单不会写入新对象。内嵌图片、组合、形状和效果保留在相应内部快照中；文件交换的边界独立列在下方。

## 变换与组合

四边中间拖柄只改变单轴；四角按比例锁决定等比/自由拖缩。任意二维角度的移动、数值尺寸、旋转、翻转和三种行列锚定消费同一几何。比例百分比、原图/尺寸/外观/裁剪重设有各自明确范围。

多选保持各对象独立柄，提供邻近浮动对齐/分布/一键组合栏；显式组合有共同框，可移动、缩放、旋转、进入叶图、解组和递归删除。排列参照在工具栏和浮动栏共享，等尺寸使用最后选中对象。组内剪切在成功粘贴时才原子移除并提取，不提前删源。

## 色彩、透明、效果和边框

独立图片与组内真实叶图共用色彩/外观入口：亮度、对比度、饱和度，已有灰度/黑白/冲淡等预设，整图不透明度，以及调色板指定 RGB 透明色。透明色是源像素色键，不等于整图透明度；当前没有在图片上点击吸取颜色的吸管。

右侧格式侧栏按填充与线条、效果、大小与属性、图片四页组织。背板填充、详细轮廓、阴影、倒影、发光、柔化边缘和三维处理有真实绘制消费者及各自预算。组填充/轮廓显式作用到真实叶图。材质/光照有本产品的有界呈现，不承诺跨桌面版本逐像素相同。

形状裁剪提供 147 项分组目录、真实路径与可调整点，支持孔、凹形和超框标注尾巴；遮罩、源采样、透明命中和另存共用几何。原图标注与最终效果双视图避免在投影面误定位，取消不改文档。

## 明确边界

- 来源支持 PNG、JPEG、GIF、WebP、有界 BMP 和自包含静态 SVG。TIFF、HEIC/HEIF、EMF、WMF 等尚不支持；BMP/SVG 的安全子集和尺寸预算见 [来源格式](picture-source-formats.md)。动画、多图总量和平台解码能力没有无限预算保证。
- 透明色当前通过调色板指定，没有图上吸色交互。宏分配、OCR/提取转换等桌面专属菜单不是现有已实现功能。
- 新框、真实组合、形状裁剪和保真单元格本地几何尚不支持 XLSX/外部图片封装；新框/组合也尚不支持打印与页布局。现有安全门明确阻断，不能无提示丢掉这些状态。显式旧图片布尔倒影升级到新框仍会原子拒绝；详细倒影参数采用当前有界模型。
- [形状裁剪](picture-shape-crop.md)、[单元格转换](picture-cell-conversion.md)、[标注](picture-annotations.md)、[排列与还原](picture-arrangement-and-original-reset.md)和[成员剪切](picture-owned-cut.md)各自记录具体合同。此范围不宣称复制所有桌面版本的全部功能或像素布局。
