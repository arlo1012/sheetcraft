# 图片形状裁剪

图片裁剪菜单及“设置图片格式 → 图片”提供 147 种形状：矩形 9、基本形状 41、
箭头 27、公式形状 6、流程图 28、星与旗帜 20、标注 16。目录不包含文本框或线条连接器。
选中状态、中文/英文名称、键盘选择与数值几何预览共用同一目录。

## 编辑合同

- 选形状只改变当前实际图片叶的遮罩，保留源资产、八个源/裁剪数值、二维角度、翻转、
  有效外观、替代文本及同组其他成员；选择普通矩形清除遮罩。
- 选择形状后进入裁剪模式。黄色调整点来自预设本身；可以指针拖动，也可以聚焦后按
  方向键微调，Shift 加大步长。没有调整点的预设不显示虚构控件。无效调整不更新草稿。
- 裁剪手势及形状调整先留在同一个草稿，局部撤销/重做只改变草稿；应用后是一次完整
  可撤销命令。Escape 应用并退出，明确“取消裁剪”丢弃草稿。命令拒绝保留草稿。
- 进入格式窗格编辑前先应用当前裁剪草稿。失败或目标变化阻止这次窗格操作；成功后
  窗格显示已提交数值。应用裁剪与随后数值编辑分别形成可撤销操作。
- “重设形状和裁剪”以及窗格“重设裁剪”清除遮罩，以当前源尺寸和未旋转源中心重建
  裁剪框，保留二维角度。“重设图片外观”清除遮罩和本地效果，保留裁剪八字段及角度。
  “重设大小”仍依据实际资产原尺寸并清二维角度，是独立操作。

## 实际呈现

遮罩是数值预设路径，包含曲线、凹形、独立路径联合与同路径非零绕数孔洞。
Arc、括号类有真实填充；标注尾巴可以超过选择框，源像素不会被原矩形二次截断。
原始源参数不被覆盖，视觉源映射使用实际填充范围。默认 Arc 因而把整个源映射到
其四分之一椭圆范围，带尾巴的标注使用包含尾巴的填充范围。

网格绘制、源预览、另存图片、轮廓、背板、透明效果及三维挤出共享该几何。
二维形状透明区域的选择命中遵循填充路径，不由选中框的不可见矩形拦截。
裁剪时灰显被排除的真实源像素，翻转、旋转与留白仍保留。拖动源按视觉像素移动；
拖动裁剪柄保留实际映射源的位置和尺寸。这是本产品的统一交互合同。

三维侧面使用真实外边界、孔与凹形，并做深度遮挡；不是矩形框挤出。
曲线误差、拓扑工作量、输出像素和缓冲都有上限，不能满足精度或预算的组合明确拒绝。
当前材质处理不是透明实体的多层光学模拟，也不承诺与所有桌面版本的光照逐像素一致。

## 保存和资源

- 实际形状遮罩的内部快照为 V52；无遮罩图片继续使用其原有版本。
  旧版本读取兼容，旧版本携带未声明的遮罩字段拒绝，不静默遗漏。
- 独立图片与组内叶均保留遮罩；复制、组合/解组、结构变更、删除后的单成员提升和
  撤销重做消费同一字段。替换图片保留遮罩及自定义替代文本。
- 源预览及另存图片保留孔、尾巴和源采样；显式另存隐藏叶可渲染该叶，工作簿可见性不变。
  非法呈现先拒绝，再读取或解码资产，不回退输出未裁剪的原图。
- 新框、组及形状遮罩仍不支持 XLSX 交换，现有安全门明确阻断；保真的单元格转换见
  [图片单元格转换](picture-cell-conversion.md)，更多图片来源格式仍需后续收尾。本功能不代表整项图片工具全部完成。
