# 公式当前范围

本阶段包含公式结构化编写、根对象与组内来源保真、组合/解组、文档内剪贴板及有界数学打印。公式保持 `kind: "equation"`，不参与单元格计算。
已有 LaTeX 原文不自动转换为结构树，也不因读取而改变对象或存档版本。

## 入口与结构化草稿

- “插入 → 公式”提供 13 个内置公式以及新建空公式；创建后进入工作表中的公式编辑面。
- 公式工具包含 8 类数学符号、11 类结构：分式、上下标、根式、积分、大型运算符、括号、函数、重音、极限与对数、运算符、矩阵。
- 结构有独立可点击槽位，支持在分子、根内、上下限及矩阵单元中嵌套结构。预设是可编辑的数学节点，不是图片。
- 新对象以有稳定节点身份的严格数学树为来源；LaTeX 是经过验证的生成投影。旧公式保留原文来源模式。
- 分式支持堆叠、斜式、线性以及去分数线。矩阵支持行列插删、列对齐；至少保留一行一列，最多 16 × 16。
- 本应用提供 Ctrl+Alt+左右方向键切换槽位、槽位边缘左右退出、同一序列内 Shift+方向键选择及相邻结构删除。未将这些快捷键宣称为桌面 WPS 的全部键盘行为；矩阵 Tab 跳格未提供。
- “普通文本”可改变选中文字的数学/普通模式，或改变随后输入的模式，不凭空插入字符。

菜单按桌面观察到的类别组织。公开数学字符和额外模板使用本应用明确名称，不将无法读取的竞品缩略图身份或符号码点作为已核事实。

## 应用、撤销与来源切换

- 私有撤销/重做作用于当前数学草稿；应用成功后形成一条对象编辑事务，可再用工作簿撤销/重做。
- Escape 和完成编辑应用当前有效草稿；“取消本次编辑”放弃草稿。取消新对象的编辑保留已创建的空对象，创建本身仍可撤销。
- 输入法组合期间不应用半成品，也不执行结构替换或矩阵命令。来源对象、工作表、文档或权限改变后，旧输入和旧菜单不写到新目标。
- 编辑 LaTeX 来源前会说明结构编辑将暂停。可以取消切换或恢复结构化草稿；没有将任意 LaTeX 自动解析为假结构树。
- 无效数学语法、预算超限或命令拒绝保留当前草稿和原对象，未成功应用不报告完成。无内容变化的结束不增加历史。
- 结构化公式内部快照按需使用版本 75；无此特性的存档继续沿原版本，旧版本拒绝未知结构字段。
- 显式采用独立 `shapeFrame` 的根公式按需使用内部快照版本 76，数学来源与位置互不覆盖；旧位置模型不因读取而迁移。公式框不赋予普通形状主体或文字布局。显式组合或数学翻转按需使用版本 77；未用新能力的存档沿用原版本。

## 渲染与边界

预览与显示使用项目已有 KaTeX 公开 API 和随包数学字体，禁止信任外链/HTML命令。语法范围是 KaTeX 支持集，不等于任意 LaTeX、UnicodeMath 或桌面 Office 格式转换。
数学树、深度、文本、矩阵、输入与输出扩展均有预算；超限给出反馈而不尝试无限展开。

当前编辑面提供语义结构与槽位；不承诺与桌面逐像素一致的字形拉伸、排版或任意跨槽原生选区。
独立根公式可移动、缩放和旋转，保留原 LaTeX 或数学树与其生成文本。通用几何编辑和准备步骤不能移除或改写数学来源。
选中对象后 Ctrl+C、Ctrl+X、Ctrl+V 使用工作簿内剪贴板；复制保留独立数学树，剪切在粘贴成功时才移除来源。支持同工作簿同表及跨表移动，权限、来源或目标变化时整批拒绝；成功移动可用一条文档撤销恢复。新对象使用新绘图身份，数学节点身份在各对象内部保留。

## 数学打印

打印预览使用 KaTeX 实际数学 DOM/CSS 的布局、基线、分数线和已就绪数学字体生成专用像素面，不将 LaTeX 当普通文字打印。公式按工作表真实对象顺序绘制；支持根公式及组内公式旋转、页边裁切及重复标题区，只有公式的工作表也计入分页范围。显式框的隐藏、折叠和“打印对象”属性由打印消费者遵守。

数学布局和字体准备完成前不提供可打印页面；字体失效、来源变更、无法消费的布局或超预算会明确阻止本次输出。每个工作表最多准备 128 个可打印公式，像素面和缓存有独立总量预算。打印支持集比屏幕 KaTeX 显示更保守，不能消费的 SVG、样式或字形不会静默省略。打印准备及失败不改变数学来源和撤销记录。

## 组合、翻转与组内编辑

公式可与公式或普通形状组合、嵌套组合及解组；共用已有对象选择、移动、尺寸、旋转、排列、显隐、剪贴板与文档撤销入口。公式成员保持自己的数学来源和内部节点身份，来源编辑只替换捕获的真正成员及其外层所有者，不修改相邻公式或形状。解组保留当前世界位置和角度。

水平翻转改变布局与数学对象的翻转身份，公式字形保持可读；垂直翻转在框内使整式转 180°，不改写几何旋转字段。双次翻转恢复原状态。显式隐藏旧位置公式时可将其升级为等价固定框，其他内容与位置保持；单纯读取不迁移。

组内 F2、双击或编辑入口使用同一语义公式草稿。结束另一公式后，重新核验真正所有者和更新后的几何租约；旧回调、过期来源或切表不写到新对象。

数学打印按真实所有者和深度优先绘制顺序处理混合形状/公式组；外层“打印对象”、祖先隐藏及折叠由同一消费者遵守。组内公式不进入普通形状文字或字体准备流程。

含公式的组暂不支持活动容器阴影/反射/发光或共享 3D 场景，相关编辑在写入前明确拒绝且保留原文档；独立普通形状组不受此限制。此限制不把公式伪造为可消费的形状主体。
原生工作簿交换没有扩展。
