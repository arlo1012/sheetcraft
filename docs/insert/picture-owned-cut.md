# 组合成员剪切

图片右键、原生剪切事件和既有源图菜单共用本地树剪贴板。根对象、组合内真实叶图和子组都可捕获；同时选中祖先与后代时只捕获祖先一次。捕获只保存脱离文档的源快照和本地令牌，不立即删除原对象。

粘贴要求同一源工作表实例、修订、所有者代次、有效几何和完整源树仍匹配。仅滚动视图不撤销令牌；换工作表、改源或真实行列几何变化会拒绝。外部相同描述、资产或对象 ID 不能获得本地剪切归属。

一次接受的粘贴原子删除精确源路径、提取原身份到目标位置，并递归解散受影响的单成员组合。剩余对象世界位置、尺寸、角度、真实资产、隐藏状态和未选中的树保留。原根移动保留叠放槽位；提取成员紧邻原所有者上方，按原遍历顺序排列。不伪造组合容器的图片源。

提取对象继承原外层所有者的有效保护和打印属性。源和目标仍分别经过现有 Core 权限，不因复制新身份、先剪切或旧叶属性放宽创建/修改权限。失败、异常或命令拒绝保留原文档、历史和本地剪切快照；成功后才消费该令牌，旧完成回调不清除新复制。一次撤销/重做恢复完整前后树。

系统剪贴板只写描述和本地令牌，不新增图片资产或完整树的外传格式。上述成员剪切是 Sheetcraft 的明确本地合同；桌面参考已测组内 Delete 的递归解组，但没有测 Cut，不能将两者混称已验证桌面兼容。
