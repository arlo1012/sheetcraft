# 插入形状：当前范围

标准形状的第一阶段已接入现有绘图编辑器。本阶段覆盖图库、画布创建、标准路径和局部编辑消费者；整个桌面形状工具仍在继续补齐。

## 图库与实际几何

- 分组目录包含桌面对应的161个入口：12线条、9矩形、43基本形状、27箭头、6公式形状、28流程图、20星旗、16标注。分类名称支持中英文搜索和键盘定位。
- 147个固定预设复用既有标准数据。九个线条入口产生实际直线或固定肘形/曲线及无箭头、终点箭头或双箭头。连接符暂未绑定其他形状。
- 横排和竖排文本框入口创建各自明确的对象。曲线、任意多边形和自由曲线三个入口使用独立的多点／连续轨迹绘制会话。
- 按实际长宽计算标准路径、逐路径填充差分与描边，保留孔洞、凹形和超框标注尾。移动、局部轴缩放、旋转选择框及黄色调整柄消费同一几何。
- 旧的九种形状保持原路径和原内部快照行为。只有新插入或用户明确从图库更改，才使用标准预设；不自动迁移旧数据。

## 画布创建

顶部“形状”菜单选择后，可以在工作表中拖动创建；单击使用默认尺寸。预览期间不改变文档，释放指针才产生一次可撤销插入。勾选“连续绘制”后保留当前工具，退出或取消不插入未提交的预览。创建状态保留工作簿的撤销重做快捷键，弹出阻挡工作表的对话框或目标、修订及权限变化会结束旧状态。

线条、静态肘形和曲线连接符保留拖动的起止方向；四象限使用明确的水平和竖直几何翻转，线端、命中、字形区域与黄色调整柄同步消费。Shift 约束普通形状为正方形、线条为45度倍数。极细线段受内部1像素尺寸约束；无法在工作表边缘满足端点误差边界时显示失败，不把错误方向或过大对象插入文档。

## 自由绘制与顶点编辑

曲线按单击节点创建平滑路径，双击终点或选择“完成”结束；任意多边形支持单击直线段和按住拖动的自由轨迹混合；自由曲线按住拖动、释放完成。单击起点或使用“闭合路径”可闭合多点路径。一次完成只产生一个可撤销对象，未完成状态不写入工作簿。短笔画、超预算或失效目标不会插入截断对象；失败保留可重试的预览。

双击已完成自由路径或右击其实际线段进入“编辑顶点”。顶点及所选节点的控制柄消费真实曲线、翻转和旋转。可以拖动或方向键微调，添加／删除顶点、选择平滑／直线／角部顶点，以及在选定节点开放或闭合路径。开放闭合路径会在所选节点切开并保留原闭合边，而不是删除最后一段；重合的两个端点提供独立选择位置。

平滑顶点的两柄反向共线、等长联动，角部顶点允许独立控制。直线顶点使用共线但保留两侧原长度的产品规则。曲线初始化使用有界的 Catmull–Rom 插值；添加顶点保持原贝塞尔曲线，删除顶点保留相邻存续控制柄，混合段使用确定性的连接规则。这些数值算法不承诺复刻桌面程序未公开的拟合实现。当前没有独立的“直线段／曲线段”转换菜单。

数字路径最多2048条命令、完成绘制最多2046个采样点；几何求值与命中点数亦有预算。大范围复杂曲线若无法在预算内完整准备，会明确拒绝插入或修改。极细自由路径保留1像素框，不在缩放时突增为16像素。

## 线条端点与箭头

标准直线、肘形和曲线连接符选中后显示真实起止端点；拖动或方向键可移动单个端点并保留另一端、原角度、预设调整及起止箭头身份。Shift 拖动按工作表方向约束45度倍数，Shift 方向键加大步长。滚动、冻结分区和显示缩放共同使用同一坐标投影；极细轴仅允许不超过0.5像素的端点误差，超界失败不会钳到错误位置。

现有编辑器提供独立起点和终点的六种箭头类型及宽度、长度各三档组合，预览与实际绘制消费相同数据。线条不显示无效的文字与填充控件，已有文字和填充数据保留。取消草稿不改文档，旧对象或旧预设回调不能修改新目标。这些连接符目前仍是独立几何，尚未吸附绑定其他形状。

## 编辑与内部恢复

调整参数及线端与撤销重做、结构变更、内部快照一致。手势取消不提交预览；对象、工作表、文档修订或权限改变时，旧会话不能提交给新目标。文本框切换失败保留现有编辑草稿。

标准形状使用有界、稀疏的参数。尺寸超过标准求值上限时使用同一比例数值映射，不分别钳制两轴。无法求值的几何明确显示错误并阻止编辑器确认，不替换成矩形。

只有标准预设使用内部快照版本54；出现线端或竖排文本框时使用版本55；使用几何翻转时使用版本56；存在自由路径时使用版本57。没有这些特性时保持既有版本。旧版本携带新字段会明确拒绝。

## 详细形状外观与格式窗格

选中形状后可由就近格式按钮打开右侧窗格。形状选项与文本选项分别保留各自标签页；数值输入以完整草稿确认，不在输入多位数字时拆成中间值。对象、工作簿、工作表、修订或权限变化会拒绝旧操作；拒绝保留可纠正的草稿。

当前已接通形状填充、轮廓、阴影、映像、发光、柔化边缘，以及三维格式与旋转。无填充、纯色、渐变、图案和用户明确选择的本地图片／纹理均消费真实像素；轮廓的颜色、透明度、宽度、复合线型、虚线、线帽、连接和线端共同绘制。阴影等效果复用现有有界绘制实现，不以字段存在或 CSS 近似代替实际效果。文字使用独立的真实字形层，随形状正面三维投影；“保持文字平面”只跳过这层三维投影，不取消对象的普通二维旋转。文字自身的三维效果按真实字形轮廓处理，不挤出外接矩形。

轮廓、填充、孔洞、凹形、超框标注尾与效果共同参与视口裁切、冻结分区及透明像素命中。画面显示使用对象自己的像素副本；缓存回收不会清空已显示的形状。纹理资源按内容身份保存，来源选择绑定明确对象，失败或过期解码不会写入新选中项。原生工作簿交换与照相机中的形状对象能力仍保留既有边界；当前打印支持见下文。

旧九种形状只有明确应用详细外观或新文字布局时才进入其原路径的数字绘制适配，不更换为另一个标准预设。现有基础填充与描边编辑会更新相应详细类别，保留其它外观；撤销重做与内部快照保留全部数据。有详细外观时使用内部快照版本58；空外观不强制升级，旧版本携带新外观字段会明确拒绝。

此阶段仍是整个形状工具的部分实现。比例、锚定、打印、锁定与替代文字等属性现已接通，具体规则见下文。多选悬浮栏、真实组合与组内叶编辑现已接通，具体范围见下文；连接符绑定和组容器的主体效果仍在继续。

## 文字布局与字形外观

形状与文本框的文字选项已接入右侧格式窗格：字体、字号、加粗、倾斜、下划线、删除线；段落对齐与前后间距、普通或固定行距；四个内边距、独立换行／溢出、起始／居中／末端对齐及固定宽度适应高度。文字填充、轮廓、阴影、映像、发光、柔化和三维效果独立于形状外观，消费实际原生字形像素。没有文字区域的线条和开放路径不显示可用的文字能力，也不生成文字错误覆盖层；已有数据保留。

六种方向为横排、竖排右至左、竖排左至右、全部文字旋转90度、270度和字符堆叠。堆叠的列顺序独立保存；普通横排保留浏览器原生文字塑形与双向排版。Unicode17竖排方向数据用于有界的直立／旋转回退，不包含全部字体的专用竖排替代字形；复杂连写脚本的逐字竖排无法安全塑形时明确拒绝。中文和所有字体的桌面排版细节仍不承诺完全一致。

字体可继承现有应用字体栈，或明确选择受管字体／已加载本机字体身份；读取工作簿不会自动枚举系统字体。缺字体、未准备好的纹理或超字形预算会保留编辑草稿并拒绝命令，不把已保存文字替换为另一种内容。格式或文字编辑的一次确认把文字、样式和必要的高度／锚点变更写入同一可撤销命令。

自动适应保持宽度和旋转后的局部上边，以原生字体测量在32次评估预算内寻找已证明可容纳的高度；不承诺任意非单调预设的全局最小高度。清空文字保留一个空行，手动改高度关闭适应模式。仅改变颜色、外观、平面保持或溢出不顺带重算文档高度；字体加载和绘制也不会自行写入历史。水平翻转保留可读字形并反映不对称文字区域；垂直翻转把文字转180度，不镜像字形或改写对象旋转字段。

绘制受100000文字单元、4096行、4MP单次像素及64MiB单次内存边界约束，复杂轮廓／虚线／三维另有命令与边预算。高显示密度若超过字形轮廓预算，会使用已经可证明的有界低密度输出；量化误差随实际像素密度变化。对象自身副本与缓存分别有预算，回收和取消会释放资源。

新建形状／文本框明确采用新文字布局；旧对象读取时保持旧布局，只有明确修改新文字属性才持久化新模型。存在该模型时使用内部快照59，旧版本不能携带新字段；没有新模型的旧对象仍沿用原版本。文字纹理的内容身份、内部恢复、复制及撤销重做共同保留，不因此新增原生工作簿交换能力。

## 尺寸、对象属性与内部恢复

内部新增独立的形状定位，三个模式分别保存逻辑起点与尺寸、逻辑两端点，或固定工作表坐标。它只负责无图片源的形状和文本框，不保存第二份宽高或旋转数据。按旋转局部左上角固定的数值缩放、稀疏行列变更、隐藏恢复和全覆盖删除使用同一几何。

新插入形状／文本框使用“随单元格移动和调整大小”，默认不锁定长宽比例、允许打印、对象锁定。选中对象后，“形状选项 → 大小和属性”提供宽高、角度、宽高百分比、比例锁、三个锚定模式、打印、锁定、替代标题和说明。数值尺寸以旋转后的局部左上角为固定点；旋转本身保留布局框与中心。侧边拖柄只改变对应轴；角拖柄受比例锁控制。

百分比以本次选中会话的尺寸为基准，同一会话150%和200%分别取同一个基准；取消选择后重选，以当时尺寸重新显示100%。这不是永远保存的“原始大小”，读取和重选不会写入文档。普通旧对象读取保持原定位；只有明确应用需要新对象属性的操作才进入独立定位，按原移动语义初始化。

普通和冻结视图的画面、选择框、移动／缩放／旋转、线条端点、自由顶点、格式窗格和编辑器共同使用可逆的临时投影视图。视图的物理宽高不进入保存数据，隐藏的逻辑起点、终点、负位置和正的亚像素跨度不被旧定位校验钳掉。隐藏导致完全折叠的对象不绘制，但原对象与恢复信息仍保留。

分页视图按纸张的真实单元格内容带分别裁切同一对象，普通旧形状仍保持原数据。移动、旋转、缩放、黄色调整柄、线条端点和自由顶点，以及形状／文本框／自由路径的画布创建，都按连续工作表坐标处理。跨页移动不会把页边距或纸张间隙算入距离；在页边距、页间空白或无法确定的区域释放不会提交旧预览。打印范围不限制分页视图中可编辑的空白单元格，超大行列也不会让纸张边距成为绘制区域。

缩放、滚动、页面投影、工作表几何、对象、权限或修订改变，会取消未提交手势。自由路径在不同纸张边缘靠近的单元格之间不会误判成点击起点闭合。完整形状工具仍有连接绑定和直接文字编辑等后续交互，不能把这一阶段等同于完整桌面工具。

内部恢复和自动保存支持独立定位；无效数据、失效目标或被拒绝的编辑保留原工作簿和编辑草稿。对象、来源与工作表几何在确认前重新核对，旧对话框不能写入新目标；待提交单元格编辑先完成，再取得最新的对象投影。

只有存在独立定位时使用内部快照60；旧对象不自动迁移，旧版本不能携带新字段。比例锁、锁定、打印、替代文本采用明确默认值和稀疏覆盖。对象保护使用产品自己的保守规则：无“编辑对象”许可时，只能修改既有未锁定对象，不能通过新对象自带未锁定标记绕过插入权限。历史恢复保留原有精确语义。无该许可时，对象的锁定状态不可修改；对象自身可编辑也不授予插入新对象权限。桌面形状保护的具体行为尚未核验。

新定位当前不支持 XLSX，导出在资源注册前明确阻断并保留工作簿；既有形状的原生格式限制不因此改变。

## 打印

形状／文本框使用自己的实际主体和字形像素参与打印，不转成伪图片对象。打印消费者保留对象顺序、二维旋转、翻转、实际轮廓与超框文字／效果，并使用当前隐藏、筛选和大纲可见性。取消“打印对象”或完全折叠的形状不会扩张打印内容范围，也不准备其字体或纹理资源。

字体、字形、画布或资源无法完整准备、超出绘制预算时，预览或打印明确反馈原因；不会把空白输出报告为成功。实际打印前等待资源准备并重新核对对象、修订和设置，以最终字形范围重建分页。打印能力没有扩展原生工作簿交换格式。

## 多选、组合与真实成员编辑

形状与文本框使用自己的有序嵌套组树。根只保存一个独立定位，成员保存相对父级的比例布局与独立角度；主体、文字、样式和纹理来源仍属于真实叶对象，不借用图片来源，也不保存第二份世界坐标。非等比缩放改变成员的局部宽高和位置，再合成角度，保持正交轮廓，不产生剪切。

内部组树使用快照61；没有组树的文档仍选择原有版本，旧版本携带组树会拒绝。拥有关系最多32层、10000个节点，并拒绝重复标识、环、共享成员和访问器。整个绘图集合还核对根与所有成员的标识冲突。叶和嵌套组的解析尺寸遵守现有16384像素上限，隐藏产生的合法亚像素跨度保留。

组合、解组、成员编辑、删除与复制的计划保持明确的拥有关系、顺序和世界位置。删除受影响组中的单个剩余成员时会消解该组；存续对象不跳位。组的外层锁定和打印属性决定成员的实际行为，解组后继承该行为；成员本身的比例、文字和其它外观仍保留。这是采用已核验图片组几何后的形状产品规则，不宣称所有桌面形状组合细节已逐项验证。

按住 Ctrl／Command 或 Shift 选择多个根对象，保留每个对象自己的手柄，并提供就近排列悬浮栏：六向对齐、双轴居中、三个以上对象的水平／垂直分布，以及排列参照与一键组合。多选整体移动使用相同位移；拖动某个对象的边柄，以相同比例改变每个对象自己的相应轴，而不是把多选对象强行当成一个持久组。角柄使用活动对象的比例锁或 Shift 约束。悬浮栏同时提供等高、等宽和等大小。它们以最后选中的对象尺寸为目标，不用整体包围框作为尺寸；等高／等宽遵守各对象的比例锁，等大小直接设置两轴。

显式组合产生真实有序拥有关系、统一外框和旋转柄，组内间距随容器缩放；点击组内实际叶对象可再次进入成员选择，双击或 F2 打开其编辑器。组边框回到容器选择，解组只释放一层，保留成员世界位置和继承后的锁定／打印属性。嵌套组的实际边框可直接选择，具有自己的移动、缩放、旋转、格式和解组入口；这些操作只修改该子树，外层定位和其它成员保持原有世界位置。嵌套解组把一层真实成员放回立即父级，保留顺序、角度和纹理身份。成员的已有主体、文字、自由顶点、参数和线端编辑保留真实源身份，不编辑伪容器图像。

组根和嵌套容器可由格式按钮或 F2 打开同一右侧窗格。容器的尺寸、角度、会话百分比、比例锁和替代文字操作针对真实容器；嵌套容器的锁定、打印和锚定显示有效外层值，不能单独改成另一套权限。混合成员值明确显示“混合”，数值框保持空草稿，不冒用第一个成员的值或零。完整输入确认后才批量应用，旧目标回调、失败、取消或失效纹理不会生成部分历史。

容器填充与轮廓应用到明确符合条件的真实成员；文字布局、字体、段落和文字填充／轮廓按每个成员自己的文字区域处理。文字阴影也是成员文字效果，解组后保留。窗格显示后代与可编辑成员数量，没有对应能力的线条或开放路径不会被强行赋予文字与填充。打开已保存的组会为整棵真实根树准备命令预检所需的文字纹理；实际编辑范围仍限制在所选子树。

组主体阴影属于所选真实容器。右侧“形状选项 → 效果 → 阴影”支持外部、内部与透视阴影及明确的“无”；它按组内真实主体和文字的透明像素合成，不填满成员之间的空白，不把阴影写进叶对象。嵌套组在自己的顺序位置完成合成，再参与外层效果，后面的成员可以遮住前面的成员和阴影。解组会移除被释放容器的阴影，仍存续的嵌套容器保留自身效果；成员本来的阴影、文字效果和其它样式保持原值。

普通、冻结和分页视图使用同一组像素和透明命中。组的阴影像素可选中真实容器，文字或主体像素仍对应实际叶对象；孔洞和透明空白不会被当成实心组矩形。组边框、成员手柄和编辑器仍针对真实拥有关系，不保存烘焙后的伪图片。主体和字形准备失败时会显示不可用状态，格式确认会保留草稿并拒绝修改，不只输出已成功准备的一部分成员。

组绘制按整棵树采用同一个有界像素密度。单边4096、单次4MP和共享64MiB的预算包含保留的组画布、命中蒙版以及视图／预览副本；超过预算会降低整组密度重试，仍无法安全准备时明确失败。退出、替换目标或失效异步请求释放自己的资源，不覆盖新对象的显示或命中。此限制会影响极大组和高密度显示的精细程度，不承诺任意规模组合均可完整绘制。

只有存在明确容器效果时使用内部快照62，包括持久化的“无”；没有该字段的组仍使用61。旧版本拒绝新容器效果，旧对象不会因打开或绘制而升级。组的映像、发光、柔化、三维主体效果，以及尚未支持的其它组文字效果仍禁用并说明原因，继续列入形状工具后续范围。

组合、解组、整体或成员的移动／缩放／旋转、排列和 Delete 都通过原子的绘图集合命令保存；拒绝保留原文档、历史与可重试选择。选择、对象身份、权限、几何或修订变化会使旧回调和手势失效。普通、冻结与分页视图裁切真正成员和组外框，跨页手势排除页间空白。显式成员文字编辑遵循其自动适应，整体组变换不会顺带重算文字高度或字体。

界面文档准入与内部打印已经消费完整组树。带容器阴影的组使用实际主体和字形的完整合成，按组根顺序参与打印；普通组继续沿真实叶对象顺序准备。外层不打印时跳过整组。预览资源准备完成后重算范围，最终打印要求完整效果和超框文字的范围已经可确定，不能用未准备好的纹理范围输出截断内容。内部恢复及撤销重做保留拥有关系，组树 XLSX 输出仍在资源处理前明确阻断。这些能力不代表整个形状工具已经完成。

## 连接符内部基座（尚未开放界面）

内部模型已有明确的自由端点与绑定端点。自由端点用连接符自身的局部比例保存；绑定端点只引用同一工作表的目标身份、标准预设和该预设的有序连接点，不保存过时的世界坐标。整个绘图拥有树共同解析目标位置，几何翻转、旋转、组内移动和解组后存续身份均使用相同关系。

当前基座保留真正的水平、竖直和可表示的亚像素端点；用于显示的最小1像素容器不能改变真实端点。极小分量无法在该容器与世界坐标之间可靠还原时明确拒绝，不把量化后的另一端点当成正确结果。零长度是明确的退化结果。目标或拥有容器隐藏后尺寸归零时，关系保持并返回暂停状态，不用虚构位置或旧路径替代。不同预设和缺失目标不能沿用旧连接点身份。复制包含目标的完整集合时会统一重建身份；只有连接符的复制、删除目标后的端点物化及其它交互仍待接通。

使用新模型的关系森林最多10000个节点、32层；单个身份最多512个UTF-16单元，所有身份及拥有路径累计最多100万个单元。返回的依赖身份字符串共同受4194304个UTF-16单元限制，超过预算会明确拒绝；未使用该模型的旧文档不因此增加这些限制。

此特性只使用内部快照63，旧版本携带新字段会拒绝；未使用连接符模型的文档继续使用原适用版本。派生路线、缓存和绘制坐标不写入快照。当前页面准入、叶／组投影与内部打印均明确阻止这种尚未接全消费者的新模型，避免把旧的定位框误画成真实连接路线。现有静态线条和连接符不升级、不受这个开关影响，图库吸附绑定尚未开放。

这是一项开发中的内部基座，不代表连接符工具已交付。自动避障、自动更换连接点与跨应用格式交换不在当前实现内；界面开放前必须闭合创建、拖端绑定、目标删除、完整绘制命中、组效果和打印使用同一条真实路线的消费者。
