# 插入形状：当前范围

当前正在把桌面形状工具接入现有绘图模型。本阶段是标准几何基础检查点，尚未开放完整图库或全部格式工具。

## 已有数据与编辑基础

- 旧的九种形状保持原来的路径、样式和内部快照行为，不自动替换成新的标准几何。
- 形状可显式携带标准预设身份及有界、稀疏的调整参数。参数随命令、撤销重做和结构变更保留。
- 标准几何保留逐路径填充模式、文字内框、连接点与调整柄。连接点数据本身不代表已经实现连接符绑定。
- 只有存在标准形状几何的工作簿才使用内部快照版本54；没有此特性时保持既有版本。旧版本携带新字段会明确拒绝。

## 同一工具后续范围

真实路径绘制、孔洞及外溢命中、旋转选择框、调整点、桌面分类图库与拖画是当前首片的后续消费者。详细形状格式、文字布局与直接编辑、多选组合、连接符绑定、自由曲线及顶点编辑仍待继续完成，不把数据目录数量当成这些交互已实现。

原生工作簿交换能力沿用现有明确限制；新标准形状不因此获得原生格式支持。
