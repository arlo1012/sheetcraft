# 文本框当前范围

独立文本框继续使用 `kind: "textBox"`、现有形状文字、字符格式、框架、组合、剪贴板和打印消费者。
旧存档读取不改变文字、样式或位置，也不会将文本框伪装成艺术字对象。

## 新建与文字编辑

- “插入 → 文本框”提供横排、竖排两个选择，随后在工作表中绘制。
- 单次创建成功后，直接进入现有画布文字编辑器；竖排采用从右到左的竖排布局。
- 新框初始为空，11 pt 黑字、白色填充、灰色 `#BCBCBC` 0.75 pt 轮廓；字体采用工作簿的正文选择。
- 初始左/上对齐，左右边距 0.1 in、上下边距 0.05 in；自动换行开启，自动适应文字和越界显示关闭。
- 新框随单元格移动和调整大小，默认不锁纵横比、允许打印、对象锁定。
- 形状图库中的横排/竖排文本框复用相同创建链。显式连续绘制保持绘制模式，不在每次创建后抢入文字编辑。
- 绘制取消不创建对象。创建与随后应用文字分别是可撤销事务；文字编辑器的“取消”保留已创建的空框。
- 创建后、进入编辑前若文档、对象、权限、忙碌状态或较新的绘制意图已改变，不会用旧回调编辑另一对象。

[WPS Spreadsheet 官方教程](https://www.wps.com/academy/how-to-insert-a-text-box-in-excel/1862990/)
描述横排/竖排绘制入口与文字格式。字体选择遵循本应用的可用资源，不承诺浏览器具有桌面 Calibri。

## 主体与文字格式

“对象格式”右侧窗格提供形状选项的填充与轮廓、效果、大小与属性，以及文字选项的填充与轮廓、效果、文本框布局。

- 主体可用实色、渐变、图案和本机图片填充，以及真实线宽、颜色、透明度、复合线、虚线、端帽和连接样式。
- 阴影、映像、发光、柔化边缘与主体三维格式、旋转共享现有像素绘制和预算校验；文字装饰与主体外观分别保存。
- TextBox 可在文字选项复用 25 项艺术字样式，保留文本、字符字体/字号/B/I/U、主体、位置和当前文字变形。“清除艺术字效果”恢复普通黑字并移除文字装饰和变形，保留字符格式；原自动适应设置仍参与尺寸计算。
- 可从普通文本框开始使用 41 项文字转换，包含无转换、4 项沿路径和36项包络变形；复用原有黄色调整、源文字编辑、翻转、命中与内部打印路径。
- 编辑文字时，预设与填充、轮廓、阴影、映像、发光只应用于捕获的选区，或用于光标处后续输入。同一文字草稿支持私有撤销；应用后作为一个文档事务撤销。输入法尚未完成时不提交半成品。
- 独立框、明确选中的组内叶与组合内符合条件的成员共享相同入口和真实源归属。组合主体阴影/映像/发光仍属于容器效果，填充与轮廓属于成员批量编辑；不会把容器效果写成叶节点效果。
- 传统对象属性对话框的基本填充、轮廓和线宽在已有详细覆盖时仍改变实际可见外观。

## 旧数据与内部保存

读取旧文本框不改变其原有 CSS 内轮廓、文字、方向、布局或位置。显式编辑非三维主体外观时，才在同一事务中保存原有效文字布局，包含原有内边距与边框占用；撤销恢复原来的旧表示。已有纯三维主体数据保留旧消费者。

仅实际保存非三维详细主体字段（含明确“无”）时使用内部快照73；没有该特性仍按实际数据保留旧版本。旧协议携带新字段明确拒绝。复制、组合、资源引用及历史沿既有所有权和原子命令处理；不会写入艺术字身份标记。

## 明确边界与剩余

- 4 项沿路径转换采用刚性独立可打印 ASCII 字形；复杂脚本需要完整 shaping，当前会明确拒绝并保留原文/草稿。36 项包络变形复用原生整段文字，受既有字体、像素和内存预算约束。
- 局部阴影/映像/发光与独立字形三维、非零共用文字柔化等高阶组合保持已有明确限制，不会静默降级；透视光标与复杂混合连写的编辑体验仍有阶段边界。
- 动态单元格文字引用尚无模型，仍是后续独立功能；不会把普通字符串改成公式来伪装链接。
- 原生工作簿交换保持已有支持边界；当前内部文本框能力不表示桌面文件交换无损。

这两片闭合常用创建与格式入口，界面细节仍待用户验收；动态单元格引用不计作已完成。
