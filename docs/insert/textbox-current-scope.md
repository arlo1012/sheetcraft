# 文本框当前范围

独立文本框继续使用 `kind: "textBox"`、现有形状文字、字符格式、框架、组合、剪贴板和打印消费者。
旧存档读取不改变文字、样式或位置，也不会将文本框伪装成艺术字对象。

## 新建与文字编辑

- “插入 → 文本框”提供横排、竖排两个选择，随后在工作表中绘制。
- 单次创建成功后，直接进入现有画布文字编辑器；竖排采用从右到左的竖排布局。
- 新框初始为空，11 pt 黑字、白色填充、灰色 `#BCBCBC` 0.75 pt 轮廓；字体采用工作簿的正文选择。
- 初始左/上对齐，左右边距 0.1 in、上下边距 0.05 in；自动换行开启，自动适应文字和越界显示关闭。
- 新框随单元格移动和调整大小，默认不锁纵横比、允许打印、对象锁定。
- 形状图库中的横排/竖排文本框复用相同创建链。显式连续绘制保持绘制模式，不在每次创建后抢入文字编辑。
- 绘制取消不创建对象。创建与随后应用文字分别是可撤销事务；文字编辑器的“取消”保留已创建的空框。
- 创建后、进入编辑前若文档、对象、权限、忙碌状态或较新的绘制意图已改变，不会用旧回调编辑另一对象。

[WPS Spreadsheet 官方教程](https://www.wps.com/academy/how-to-insert-a-text-box-in-excel/1862990/)
描述横排/竖排绘制入口与文字格式。字体选择遵循本应用的可用资源，不承诺浏览器具有桌面 Calibri。

## 已复用与待补范围

文本框已共享文字排版与字符填充/轮廓、移动缩放旋转翻转、分组/组内编辑、选择窗格、
文档内剪贴板、保护与内部快照/打印路径。传统编辑对话框的基本填充和轮廓仍可用。

当前只闭合独立插入及立即编辑入口，详细主体填充/轮廓/效果、25 样式、从空白文本框开始的
41 项文字变形、选区局部阴影/映像/发光仍待下一阶段统一准入与消费者。已有文字变形和主体三维数据保留。

动态单元格文字引用尚无模型；原生工作簿交换继续保持已有明确边界。本阶段不构成全部桌面文本框能力交付。
