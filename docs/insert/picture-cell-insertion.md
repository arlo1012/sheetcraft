# 本地图片嵌入单元格

从本地文件插入单元格图片与浮动图片转换使用明确的覆盖确认。单文件和批量文件
只要实际目标区域已有内容，就先列出所有目标及非空数量；确认前、取消后都不修改
原内容。空字符串、公式、已有图片和合并区域中的已有内容也属于非空。

- 文件选择开始时捕获首个目标，文件数量确定后在第一张解码前捕获整批目标。
  合并区域按实际锚点放置，批量向下跳过该区域。重复或重叠目标不接受。
- 解码、资产存储及最终确认均复核文档/工作表身份、目标合并拓扑、全部稀疏内容和
  写入权限。任一目标变化就拒绝整批，不使用旧确认覆盖新编辑，不部分插入。
  修改无关单元格或只修改样式不会使未变化的内容确认失效。
- 明确确认后，整批图片由一个命令提交，一次 Undo 恢复原内容，Redo 恢复插入结果。
  相同的现有图片是无变化，不产生确认或新历史。命令失败保留确认与原文档，旧确认、
  取消回调或重复点击不会消费更新的插入请求。
- 图片资产可能已经完成本地准备，但拒绝和取消不会改动单元格或历史。目标变化时
  会提示取消并重新选择；失效确认不会自动改为批准新的内容。

图片文件仍遵循 [来源格式与预算](picture-source-formats.md)。浮动图片/组内实际叶图
转换的几何、元数据和源/目标保护合同见 [保真图片转换](picture-cell-conversion.md)。
