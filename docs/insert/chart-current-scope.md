# 统计图当前范围

当前已接通所选图表的上下文工具、真实元素位置、有序实时系列来源、常用详细格式窗格、图表打印与剪贴板，以及常用二维子型、八种本产品样式、十一项柱形快速布局和底部数据表。现有12图型继续保留，统计图完整工具仍在推进；本页只列已接通的实际能力。

## 可发现的入口

- 单击图表后显示“图表工具”。“添加图表元素”可编辑标题文字与位置、适用图型的图例与标签；“更改图表类型”和“选择数据”打开捕获当前对象的编辑面。
- 标题支持无、图表上方、居中覆盖。图例支持无、四边和右上；不重叠选项真实预留绘图区，覆盖模式保留原绘图区。
- 柱形和条形标签支持居中、内部末端、内部起点、外部末端，正负值和堆叠段按实际方向定位。其余图型仅提供已经被对应绘制器消费的标签开关。
- 普通范围来源提供“切换行/列”；透视关联图和缓存来源不显示无效切换。来源编辑的取消不修改图表；源单元格变化由现有实时图表消费者显示。
- 图例、标签位置和堆叠开关按类型显示，不能支持的选项不会成为可点但无效果的按钮。切换图型保留已保存的暂不适用位置，回到支持类型后仍可使用。

## 快速布局与数据表

- 柱形图的“快速布局”提供11项完整布局。悬停或键盘聚焦进行临时预览，移开、Escape或关闭恢复；选择后一次应用，并可撤销。预览不修改工作簿或占用历史。
- 格式窗格可分别显示/隐藏轴标题和主/次网格线；编辑轴标题会显示新的标题文字，隐藏仍保留已有文字。布局实际控制标题、图例、标签、轴标题与主/次网格，覆盖带底部数据表、满宽柱、重叠柱等组合。已有标题与轴标题文字、来源、颜色、数值格式及对象尺寸角度保留；空轴标题按界面语言补默认文字。
- 布局6以最后类别显示“系列名、原始数值”；布局10以最后系列显示内部末端标签。间距、重叠和细网格密度为本产品明确数学配方，不承诺与其他版本的隐藏参数完全一致。
- “添加图表元素”里的数据表支持柱形、折线、面积图，可选带图例标示或无图例标示。列按实际分类轴顺序对齐，系列标示使用实际颜色，值来自完整来源并沿用系列数值格式。百分比堆积的数据表仍显示原始值，空值保留为空。
- 数据表最多32个类别、8个系列、256个数值位置，需要至少48px列宽、20px行高与96×96px绘图区。数字不截断、不缩成微小文字；长名称可省略显示但来源保留。空间或格式预算不足时，布局、元素、源编辑及格式编辑在最终绘图准备失败后不写对象或历史，并提示放大图表或减少数据及数字格式长度。
- 普通源单元格编辑仍照常进行；若新数据使已有表无法完整排布，图表提示数据表不可用，可放大图表、缩短格式或关闭数据表。内部保存、复制、剪切与打印保留并消费这些设置；其他图型保持设置但暂不显示数据表，界面明确说明不适用。

## 选择数据

- 柱形、条形、折线、面积和雷达图的“选择数据”提供系列列表、分类标签和实时预览。可以添加、编辑、删除、上移或下移系列；重新排序保留各系列的颜色。最后一个系列也可以删除，保留图表对象和尺寸，内容为空白。
- 系列名可填写文字或引用本工作簿的一个单元格；系列值可引用一行或一列，也可填写有限数值数组，例如 `={10,20,30}`。分类标签引用一行或一列，或使用自动编号。各个引用可以来自不同工作表。
- 范围选择器支持切换工作表，结束后返回原图表的工作表和选中对象。输入框也可直接填写引用。改变来源不改变标题、位置、尺寸或其他图表格式。
- 子窗口的确定只修改父窗口草稿。父窗口取消不修改文档；确定把整个来源修改合并为一次文档撤销记录。应用失败保留草稿，不产生半更新。输入法组合未完成时不会确认半成品。
- 普通矩形来源保留表头、行列方向及隐藏数据控制。开始自定义系列后，矩形范围不再是数据真源，行列方向与表头控制隐藏；显式重新应用一个矩形范围会替换当前自定义系列。
- 来源单元格的数值或公式结果变化实时更新图表，不另外产生图表撤销记录。插删、移动源单元格或工作表的内部操作维护绝对引用；删除来源后显示失效状态，不回退到旧范围。撤销结构操作恢复原引用。

当前支持同工作簿的单行、单列和单单元格引用，不支持外部工作簿、联合范围或任意系列表达式。最多256个系列，来源与输出合计最多10,000个单元格。文本、空白和错误值保留诊断，不作为数值零绘制；不等长或失效引用不能作为新的有效来源确认。透视关联图、缓存来源及其他图型继续使用已有编辑入口，不冒充已支持此系列模型。

## 子型与样式

- 插入菜单、更改图表类型窗口和所选图表的“图表子型”共用实际子型定义。柱形、条形和面积各有普通、堆积、百分比堆积三种；折线另区分有标记和无标记，共六种。已有折线默认仍显示标记，明确选子型才改变；逐系列标记不一致时不虚报统一子型。
- 百分比堆积保持原来源数值、缓存和透视数据，显示阶段按分类和主/次轴分别归一化。各轴内用绝对贡献之和作分母，混合正负值保留符号；空值不画成零。该混合正负规则是本产品明示数学，并不承诺与所有桌面版本相同。数据标签和提示继续显示原值。
- 百分比轴默认显示百分比；最小/最大值及主/次单位在窗格中输入百分比点，例如20表示20%。手动数字格式作用于比例值，选择通用格式可显示0.2。来源格式链接在此子型中不提供无效开关；旧设置保留，退出后仍可使用。
- “图表样式”提供彩色、办公、森林、暖色、冷色、单色、深色、简洁八套自有配方和真实缩略图。配方更改调色板、背景、标题与适用轴/绘图区的外观；保留来源、缓存、透视关系、元素位置、轴范围与单位、数字格式、主/次轴及线宽/平滑/标记。当前已定义系列的单独颜色被配方替换；不在当前来源中的旧系列设置保留。
- 样式选中态由已保存外观判断，没有另存容易漂移的样式编号。深色样式的图例、分页和标签使用可读缺省字色；现有明确标签样式仍保留。词云、屏幕图表与打印共用实际背景和调色板。
- 图库修改现有对象时形成一次撤销记录。标题草稿可与随后子型或样式一起原子应用，输入法未完成时不提交；更改图表窗口仍是草稿，取消无文档变化。这里的八套样式是Sheetcraft配方，不是已确认的WPS样式目录。

## 元素详细格式

- 图表工具中的“图表元素”选择器和“设置所选元素格式”打开右侧格式窗格。图内标题、轴、实际系列及绘图区可直接选择，双击打开对应窗格；系列按稳定身份定位，不按同名文字或列表顺序猜目标。
- 标题支持字体、字号、字色、粗体、斜体，文字和位置继续使用原元素设置。绘图区支持实际背景色、边框色与宽度。分类轴支持显示、反序、标签角度、轴标题和文字/轴线格式。
- 柱形、条形、折线、面积和散点的值轴支持自动或手动最小/最大值、主/次单位、反序、轴标题和文字/轴线。手动范围必须有有限正跨度；每轴最多2,048个刻度，明确次单位须整除主单位且最多100等分。超预算不应用，保留输入草稿。
- 数字格式复用单元格的通用、数值、货币、会计、日期、时间、百分比、分数、科学、文本、特殊和自定义格式。标签格式不改变数据数值；自定义负值颜色实际显示。链接来源按当前轴上系列的一致格式显示，格式混合时使用通用格式；手动选择格式会解除来源格式链接。
- 自定义来源的柱形、条形、折线和面积系列可选择主轴或次轴。两轴各自缩放，柱系列按轴分别布局并在同类别中心叠放；逻辑系列和图例仍保持来源顺序。系列颜色按稳定身份保存，折线/面积支持线宽、平滑、标记，雷达支持实际颜色、线宽和标记。
- 柱间距和系列重叠是全图属性，可从全图或柱系列窗格修改；两个轴的柱组分别消费相同布局设置。排序、删除、暂时切换图型时保留不适用的系列格式，只有原稳定身份恢复后才再次使用。
- 当前逐系列详细格式需要自定义来源的稳定系列身份。普通矩形、透视和缓存图仍可设置标题、绘图区和适用轴；对应提示说明逐系列限制，不把位置或名称当成身份。
- 数值输入在完整输入后按Enter或失焦应用，不按每个数字创建撤销记录。无效、过期或被权限拒绝的输入保留草稿；输入法组合期间切换同图元素或关闭窗格会被阻止。每次成功格式修改可独立撤销/重做。
- 受管字体与已保存的本机字体别名沿现有字体资源加载；资源缺失时显示替代字体并提示重试。系统字体的可用性仍由当前设备决定。

## 修改与持久化

操作保持来源与几何，只修改捕获对象，形成文档撤销记录；无内容变化不增加记录。应用前结束当前有效编辑并重新核验对象、工作表、文档与权限。切表、换图、删除及撤销恢复后的旧菜单不改写新实例。输入法组合未结束不提交半成品标题。

稀疏元素设置仅在显式操作后保存，内部快照按需使用版本78；有序系列来源按需使用版本79，详细格式按需使用版本80，百分比/标记/调色板/背景按需使用版本81，数据表、标签内容/作用范围及轴标题和网格选择按需使用版本82。旧图表不因读取而添加字段或升级存档。已有旧版本读写路径继续保留，新位置设置、系列来源、详细格式和本片外观设置不能静默通过旧原生导出：XLSX导出会明确停止并列出图表位置，工作簿内容不变；堆积柱形/条形/折线/面积也明确阻断，不当成普通图导出。原生工作簿格式能力没有扩展。

## 图表打印

- 页面布局的“打印预览”包含当前12图型的真实图表内容。图表沿当前来源、元素位置、详细格式和尺寸绘制；预览和最终页面使用同一图表消费者，保持图表与形状、公式对象的层叠顺序。
- 图表位置、旋转后的边界和隐藏行列进入分页范围。跨页图表按实际页面边界剪裁；打印区域、重复标题以及黑白选项沿已有页面规则消费，不把页间空隙当图表距离。
- 打印准备时捕获当前图表实例、来源数据和工作簿计算周期。换表、改数据、换图、删除或旧异步返回均不能继续输出旧内容；失效引用、过量数据或缺少可信字体资源会明确停止打印，工作簿和撤销记录不变。
- 系统字体沿当前设备的原生字体选择。已选受管字体和内容寻址本机字体使用同一已核验来源的独立临时字体面，字体加载完毕后再进行第一次图表测量与绘制；不会扫描本机字体或另外请求权限。未知动态CSS字体的原始资源不能确认时明确拒绝。临时字体仅用于本次打印，并随打印资源释放。
- 当前每工作表最多128个图表，图表数据合计最多100,000个值，单个标签最多4,096字符、单图文本最多256 KiB、全表图表文本最多1 MiB。图表像素副本全表最多32 MiB，单图最多8,388,608像素、单边最多16,384像素；超限应缩小图表或打印缩放。字体准备最多16个字体面、32 MiB源数据。以上是本产品的安全预算，不是所有浏览器的容量保证。
- 词云复用当前屏幕的排列、文字大小和调色板，以原生Canvas绘字。SVG与Canvas的中线基线定义可能带来小的字体相关偏移；不承诺不同设备像素一致。

当前Chart模型没有独立的“打印对象”或持久隐藏字段，不能套用形状或图片的属性。图表组合仍列在后续范围中；本次打印不扩展工作簿原生格式。

## 图表复制与剪切

- 单击图表可使用Ctrl/Cmd+C、X、V，也可从图表右键菜单复制、剪切、粘贴。剪贴板是本工作簿内的对象数据，不向系统剪贴板写入图表私有数据，也不涉及外部文件。
- 当前12图型均可在原工作表复制、重复粘贴和剪切；保留来源定义、标题、元素位置、详细格式、尺寸与角度。新对象只取得新的外层身份，系列身份与颜色保持。剪切在成功粘贴时才删除原图；失败保留原图和剪贴板。
- 同一工作簿内可跨表复制或剪切已有明确系列来源的图表与静态缓存图。绝对来源仍指向原工作表；不会重指到目标表同地址，也不会把实时来源变成静态值。
- 旧矩形来源的柱形、条形、折线、面积、雷达图，在可证明可见数据和颜色保持时，跨表粘贴会改为明确指向原表的实时系列来源。其他旧矩形图型、仍关联透视表的图，或会激活旧隐藏系列格式的情况，跨表操作明确拒绝。可在原表粘贴，或先在“选择数据”中设置支持的系列来源；原图和剪贴板保留。
- 跨表剪切以一次原子事务修改两张表，一次撤销或重做同时还原两侧。源表和目标表权限分别检查；切表本身不使剪切失效，文档修改、对象重建或过期菜单不能误改新对象。目标坐标、行列几何和来源归属在应用前重新核验。

## 仍待闭合

- 非柱形图的快速布局、条形及其他图型的数据表，更多桌面图型与子型（包括三维、复合饼图和组合图）；更多轴属性（对数、交叉、显示单位等）和高级元素效果。
- 系列筛选、更多来源表达式及其他图型的系列来源编辑。
- 图表对象组合，以及上述明确限制之外的跨表来源迁移。

现有12图型不等于桌面目录全部类型或子型。簇状柱/横条/有界折线的历史原生范围见各自说明，不能由本片位置控件推导全部原生支持。
