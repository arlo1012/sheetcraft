# 公式编辑与公式工具

公式页、公式栏和格内编辑共用一个草稿会话。公式工具只发出“插入函数”“插入跨表引用”“管理名称”等编辑意图；会话 owner 负责文本、光标、输入法、焦点和最终提交，因此所有入口仍只产生一次 Core 命令和一条历史记录。

## 公式页与函数浏览

Ribbon 的“公式”页读取 Core 当前注册的 **240 个函数**，并按数学、逻辑、统计、兼容性、数据库、查找与引用、信息、文本、日期、财务和工程分类显示。函数数和分类以注册表为准；类别、函数说明、参数签名和示例都有中文、英文文案。函数浏览器支持按名称/说明搜索、按类别筛选、查看最近使用函数、帮助签名和示例，再插入所选函数。

选择函数会在草稿光标处插入 `NAME(`。若没有正在编辑的草稿，工具先以活动单元格创建公式栏会话；若已有草稿，则保留已有文字和选择范围。函数插入后继续使用同一套参数提示、补全、引用选择和提交规则。

自动求和保留分体按钮：主操作根据活动单元格上方连续数值优先、左侧连续数值其次，推断一个 `SUM` 范围；下拉菜单可插入常见汇总函数。它是邻近数据猜测，不是表格、筛选或多选区域的智能填充。

## 草稿、补全与引用

输入 `=s` 可用 Tab/Enter 接受候选，形成 `=SUM(`；函数帮助显示当前参数签名。点击、拖选或键盘扩展选区会把引用插入当前公式位置。Enter/Tab 接受候选时不会提交；确认草稿后才写入原编辑目标。

- 公式栏与单元格编辑器同步显示同一草稿。Esc 取消，Alt+Enter 换行；输入法组合期间不接受候选、引用或提前提交。
- F2 在文字编辑和引用选择之间切换；F4 循环 `A1 → $A$1 → A$1 → $A1 → A1`。提交前只补齐可合法补齐的末尾右括号。
- 公式文字和网格引用框按范围配色；字符串中的类似 A1 文本不会被当作引用。
- 拖选复用网格命中、冻结窗格和边缘自动滚动。编辑目标固定在会话开始时的 Sheet 和单元格，切换活动位置不会误写草稿。
- 编辑器可插入矩形、整行和整列引用。数组公式会显示溢出投影；在公式中输入或插入 `A1#` 可引用该根公式的整个溢出范围。

跨 Sheet 编辑期间可切换工作表并在目标表点选或拖选范围；工具会插入带正确引号转义的 `Sheet!A1` / `Sheet!A1:B2`，再回到原表继续编辑。引用显示只高亮当前可见表内对应范围。公式只能引用当前工作簿的 Sheet，不能引用外部工作簿。

## 名称

名称管理器可新建、编辑和删除工作簿级或工作表局部名称，也可由当前选区创建。名称定义为一个已存在 Sheet 中的矩形引用；局部名称在其所属 Sheet 的公式中优先于同名工作簿名称。保存和删除通过 Core 命令，支持撤销重做，并随 V8 快照和 XLSX 的受支持名称子集交换。

## 边界与验证

编辑器不保存计算缓存、函数目录或草稿状态到工作簿。可输入[结构化表格引用](features/table-styles.md)，如 `=SUM(Table1[金额])` 和 `=[@金额]`。计算能力和不支持的语法见[公式运行时](formula-runtime.md)：外部工作簿、3D 引用、LET、LAMBDA 和通用隐式交集 `@` 仍不可用，不能据此宣称完整 Excel/WPS 兼容。

定向 Web 验证位于公式工具、共享公式编辑和工作簿模块测试；涉及引用、焦点或跨 Sheet 点选时，再补真实浏览器检查。
