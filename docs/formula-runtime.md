# 公式运行时第一版

Core 提供运行时无关的解析、求值和函数注册表。Web 的候选列表与参数顺序读取同一份元数据，
已审核的 521 项目录仍是完整兼容目标，不是产品已实现的函数集合。

## 已实现

- 同表 A1、绝对/混合引用、矩形范围、括号和四则运算。
- 文本字面量（双引号用 `""` 转义）、TRUE/FALSE、`&` 连接，以及 `= <> < <= > >=` 比较。
- SUM、AVERAGE、COUNT、MIN、MAX 聚合；IF 和 IFERROR 按需计算分支；ROUND 小数舍入。
- 错误值沿表达式传播，IFERROR 可选取备用值。COUNT 忽略引用/范围中的错误，但直接错误参数传播。
- 聚合区分直接参数和单元格引用：引用中的文本与布尔值不参与数字聚合；直接布尔/数字文本可参与。
- 惰性条件存在于嵌套表达式时仍先计算条件需要的引用，再访问选中的分支。
  未选中的自引用不制造循环错误，实际选中的循环仍返回 CYCLE。
- 稀疏范围只遍历已存单元格，单元格依赖链使用显式栈；测试包含 15,000 个嵌套 IF 单元格。

## 边界

这是完整 Excel 兼容计划中的首批实现，不是完整 Excel/WPS 计算引擎。
未实现函数返回 NAME，未支持语法返回 PARSE；不使用 XLSX 文件中的缓存结果伪装计算成功。
跨表、整行整列、名称、结构化引用、动态数组、区域相关的文本转数值规则和完整隐式类型转换尚未实现。
普通四则运算目前接受数值及空单元格（按零处理），不隐式转换文本或布尔值。
ROUND 采用十进制指数位移处理常见舍入中点；超过当前数字精度/位数边界可能返回 NUM。
函数注册表不依赖 Vue、DOM、i18n 或文件读写库，公共调用方也可传入自己的函数定义。

验证命令：`bun run test:core`、`bun run typecheck:core`；Web 候选和共享会话测试位于对应模块目录。
离线兼容目录和功能测试不能替代未来的 Excel 对照结果库。
