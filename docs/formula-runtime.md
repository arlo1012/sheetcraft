# 公式运行时

Core 提供与运行环境无关的公式解析、计算、函数注册和工作簿级求值器。函数元数据是唯一目录来源：Web 的分类、候选、参数顺序和帮助内容都据此显示；Core 不依赖 Vue、DOM、i18n、存储或 XLSX 库。

当前默认注册表有 **240 个可计算函数**，涵盖数学、逻辑、统计、兼容性、数据库、查找与引用、信息、文本、日期、财务和工程分类。这个数字来自当前注册表，随实现增减；它只描述已实现函数，不等同于 Excel/WPS 的完整函数目录。

## 计算与引用

- 支持数值、字符串、布尔值、错误值、括号、数组常量、`+ - * / ^ %`、`&` 和比较运算。
- 支持 A1、绝对/混合引用、矩形范围、整行/整列范围，以及同表和带工作表名称的跨 Sheet 引用。工作表名可使用单引号及转义单引号。
- 支持工作簿名称和工作表局部名称。名称解析优先使用当前工作表局部名称，再使用工作簿名称；名称可指向单元格或矩形范围。
- 支持动态数组结果及其溢出投影。`SEQUENCE`、`FILTER`、`SORT`、`UNIQUE`、`TAKE`、`DROP`、`HSTACK`、`VSTACK`、`CHOOSECOLS`、`CHOOSEROWS`、`TRANSPOSE` 等会返回数组；`A1#` 可引用某个数组公式的整个溢出范围。已有内容、合并单元格、其他溢出范围或工作表边界阻挡溢出时，结果为 `#SPILL!`。
- `createWorkbookEvaluator(workbook, sheetId)` 使用显式 frame 栈调度跨 Sheet、名称、溢出和惰性分支依赖，避免深引用链递归。Canvas 等运行时可直接使用它；`createSheetEvaluator` 保留为单 Sheet 的隔离求值器。
- IF、IFERROR、IFNA、IFS、SWITCH 的依赖选择与实际分支一致；未选中的自引用不会制造 `#CYCLE!`，实际循环返回 `#CYCLE!`。
- 日期函数从 Workbook 的 1900/1904 日期系统读取序列值；TODAY/NOW 的时钟可由计算调用方注入。

## 计算模式

计算策略是工作簿持久化设置，计算结果和溢出投影仍是可重建的派生状态，不写入单元格内容。

- 自动模式会在工作簿编辑后重新计算受影响结果。
- 手动模式保留上一次有效计算结果，直到调用方明确重新计算。
- 可启用迭代计算，并配置最大迭代次数和最大变化量，以处理标量循环计算；关闭迭代或循环依赖自身的溢出投影时返回 `#CYCLE!`。

## 函数与错误语义

函数按参数元数据验证数量并返回 FormulaValue。常用聚合、条件聚合、文本、日期、查找、数据库、财务、工程和动态数组函数均有实现；函数的精确参数和示例以注册表及 Web 函数浏览器为准。

计算避免把 JavaScript 的 `NaN` 或无穷值写入结果。错误值沿表达式传播；IFERROR 和 IFNA 只在对应错误条件下计算备用参数。聚合范围、整行/整列范围和依赖发现按稀疏存储遍历。需要二维矩阵的数组、查找与数据库运算最多展开 100,000 个单元格，超出限制返回计算错误。

## 名称、历史与文件交换

- 名称通过 Core 的 upsert/delete 命令修改，因此与普通工作簿命令共用历史和撤销重做。
- 工作表重命名、删除、插入/删除/移动行列会重写受影响的跨 Sheet 引用、整行/整列引用和名称范围；删除工作表的逆命令会恢复原公式和名称。
- 工作簿快照 V9 保存日期系统、计算设置与名称定义。
- XLSX 导入导出支持单一矩形引用的工作簿级和局部名称；无法表达的定义会记录兼容性省略，不以缓存计算值代替计算。

## 当前边界

公式只能访问当前工作簿中的 Sheet；外部工作簿引用、3D 引用和结构化表引用不支持。LET、LAMBDA 和隐式交集 `@` 也不支持。完整 Excel 隐式类型转换、区域相关文本数值规则和未注册函数同样不在当前范围；未注册函数返回 `#NAME?`，不支持的语法返回 `#PARSE!`。

定向验证位于 `packages/core/src/tests/formula`。变更公式契约时至少运行对应场景测试和 `bun run --filter @idea10/core typecheck`。
