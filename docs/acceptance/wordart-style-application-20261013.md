# 已有艺术字样式应用 — 2026-10-13

## 当前片范围

已有现代艺术字可以从文字格式窗格重新选择同一套 25 个样式，或使用“清除艺术字效果”。
根对象、组内成员、符合条件的组合成员共用真实对象归属、素材预检和原子命令。
普通形状、连接线和旧艺术字不因相似外观自动加入该作用域。

- 重套替换完整字形外观，清除局部填充/轮廓覆盖，保留用户文字及字体、字号、B/I/U。
  文字布局、转换、翻转、框、二维角度和主体/共同场景保持；真实写入明确采用保几何准备方式。
- 清除移除字形效果和文字转换，恢复黑色无轮廓；保留用户字符格式与二维角度。
  继续使用已有自动适应消费者，不重新插入占位对象。这是明确产品规则，未照抄桌面默认字号样式的副作用。
- 组合混合状态与符合条件的成员数量可见；未参与成员不变化。
- 源文字尚在编辑时，两个对象级操作明确要求先应用文字；不会强行提交组合输入半成品。
- 非法预设、旧回调、权限/繁忙/资源失败保留工作簿和历史。
  缺少保几何写入能力的独立宿主对重套操作失败关闭，不回退到可能重新适配尺寸的路径。
- 当前片不新增 Core 模型或快照版本。选区预设及局部阴影、映像、发光单独继续，不以全对象效果替代。
