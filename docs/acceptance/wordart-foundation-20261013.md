# 现代艺术字基础阶段代码验收 — 2026-10-13

## 交付范围

本阶段建立现代艺术字的严格对象合同、25 样式插入、占位文字编辑、选区字形填充/轮廓、
组与共享场景生命周期、文档内对象剪贴板和版本 70 内部快照。旧艺术字模型没有自动迁移。
准确入口与仍待完成的文字变形见 [产品范围](../insert/wordart-current-scope.md)。

首个样式采用桌面实测的黑色粗体及文字阴影参数；其余 24 个为产品自有配方。
没有使用专有样式资源，也没有把标准文字变形或整项桌面艺术字描述为已完成。

## 实际失败与修复

- 真实 Workspace 插入命令更新了 worksheet metrics，立即开始文字编辑会捕获旧 grid metrics。
  编辑入口改为等待存储根和 grid 刷新后，复核工作簿、工作表、代次、修订和根身份才开始编辑。
- 选区格式入口以前只处理基本字体字段。现在填充与轮廓进入同一 text/runs 草稿，并由真实字形绘制、
  边界、装饰线、资源归属和像素预检消费。明确 None 与继承独立。
- 无换行的大字号占位文字无法通过普通固定宽度 AutoFit。现代矩形艺术字按自然文字宽度适配，
  普通形状仍保持旧合同，预算和真实行高预检没有删除。
- 真实准备器把新身份的已缩放组内成员重新 AutoFit，复制后宽度缩小一半；剪切解组的存续成员也受影响。
  放置/归属转移改用显式保几何准备，保留 AutoFit 属性并继续执行真实布局、字体、素材和像素预算预检。
- 缺少字形纹理的 paint plan 被数字预算证明误判通过。现在 plan 本身必须 ready，失败保留原数据、历史和剪贴板。
- 异步 grid 刷新后的选中带有 owner、修订、根与显式 selection revision 守卫。
  复制文字、单元格或图片会替代先前的形状复制；延迟复制完成只清自己的旧剪贴板身份，不能清较新的复制。
- 对象与组的字体颜色读回使用当前工作簿主题，主题色与同值 RGB 不再误报混合。
