# 艺术字标准文字变形数学阶段 — 2026-10-13

本片是下一阶段的资源、严格纯数学与真实 alpha 映射底座，尚未开放文字变形入口，
没有新增文档字段或快照版本，不能据此把完整艺术字描述为已经交付。

## 已落地合同

- 保留官方 ECMA-376 第五版原始 XML、来源哈希及完整适用 notice，确定性生成
  40 个活动文字变形、88 条有方向的开放边界。No Transform 为单独的无变形语义；
  textPlain 仍是活动变形。四项 val cd2 默认值解析为标准角度常量。
- 保留 source-order guide 计算，包括 textButtonPour 中实际存在的同名 guide 后续赋值，
  以及负扫角、近整圈开放接缝、真实调整柄和多轨/多带身份。
- 复用既有固定 DrawingML 公式引擎；不接收用户 XML、公式源码或任意运行时目录。
  普通 187 个主体形状的 evaluator 和预算未修改。
- 弧长采样按线、二次/三次曲线及有向椭圆独立收敛，位置与长度误差、深度、采样数和
  数字存储均有显式预算。超过预算或无法证明精度会失败，不返回假直线。
- envelope 的上下边分别使用同一归一化弧长比例，然后按源文字纵向比例插值。
  过悬需要显式有界策略，不暗中钳制；常量边、零长度 baseline 与纯空白有独立结果。
- Web 源几何来自未裁剪的原生 ink 与作者空格 advance，与可见填充、轮廓、效果和
  contentRect 分开。源行按真实身份捕获，不能重复、丢弃或改写源文字。
- Web alpha mesh 使用共边一致的自适应三角形、逆向双线性采样及确定性的折叠绘制顺序。
  整体与选区 mask 可共享相同 mesh 和目标坐标系；色彩采样、轮廓与效果仍由随后集成消费。

## 有界限制

- 采样上限为每边 4096、每对象 8192、深度 16；数学坐标和 extents 分别有独立有限上限。
- mesh 上限为 16384 顶点、32768 三角形、4096 单边、4MP 输出、128M 加权工作量和
  64MiB 已计字节。原生源 backing buffer、其它活跃 scratch 及延迟回收的数字分配分别计入。
- 任意 callback 的有限探针不构成探针之间的数学 supremum 证明；该精度范围明确保存在 plan。
  调用方还须计入固定公式/弧长映射本身的工作与存储，不能只计 mesh 数字数组。
- baseline 的连续 alpha 映射是有界数学能力，会弯曲字形内部像素，不能当作桌面的刚性
  glyph/cluster 放置已完成。实际 Follow Path 字形支持方案仍在下一阶段。
- 本片不决定所有源行数的多轨/多带分配，不启用变形图库、文档变形字段或原生格式能力。
