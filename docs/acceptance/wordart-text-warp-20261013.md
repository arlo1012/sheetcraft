# 艺术字文字变形集成 — 2026-10-13

本阶段将已保全的标准资源和数学接到真实现代艺术字、格式窗格、字形消费者与历史。
最终界面细节仍由用户验收；标准几何示意与代码边界回归不代表桌面像素等价。

## 产品合同

- 41 选择：无转换以字段缺席表示，4 Follow Path，36 envelope；textPlain 是活动变形。
- 严格稀疏 `shapeText.warp`，实际使用时快照 71；旧对象/无活动变形保持原有版本。
  不推断旧 kind=wordArt，不迁移普通形状。非法、继承、访问器、未知字段载荷拒绝。
- 整行 envelope 保留原生字体排版；刚性路径明确限可打印 ASCII、水平 LTR、独立字形，
  不含跨字 kerning/ligature。拒绝复杂文本而非以柔性 alpha 模拟路径字形。
- 源行只分配一次，各轨共用源 advance 域；实际 native tuple 与字体就绪版本绑定布局。
  文字、尺寸、字体、变形或就绪版本变化后，旧布局不能用于新字形操作。
- 调整柄有单独身份与事件，真 textRect 域和主体框反射；主体 geometry、尺寸、文字及外观不被改写。
  XY/polar 动态范围与不可达/退化输入严格有界，最多 512 次实际 evaluator 调用。
- 根/owned/组批量操作保真实来源；失败保选择和数据，旧异步回调不能影响新对象。
  编辑直排源、应用恢复变形；取消与组合态保留既有同草稿事务。
- 实际 alpha 路径消费字符填充/轮廓、装饰线、效果、H/V 反射、透明命中与共享叶/打印源。
  输出轮廓在变形后描绘，不跟随 envelope 拉伸宽度。
