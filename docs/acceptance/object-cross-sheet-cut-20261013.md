# 同工作簿对象跨表剪切 — 2026-10-13

## 本片合同

形状、普通文本框、现代艺术字及完整组合支持当前工作簿内的跨工作表剪切。
剪切捕获不删除源对象，目标接纳成功后才一次替换两张工作表的对象集合。
完整逆命令在两侧写入前构造；一条文档历史同时恢复源与目标。

切换工作表和选择目标地址属于导航，不使剪切失效。捕获后修改文档、撤销重做、
更换来源对象、行列几何或工作簿会使旧剪切拒绝，保留原对象和内部剪贴板。
源与目标分别检查权限、完整对象森林、真实文字、连接路线与素材；失败不部分转移。

转移采用新对象身份，保留源文字、局部格式、隐藏状态和资产引用。
完整选区内的连接重新对应新身份；动态文本框仍指向原工作表的绝对单元格来源。
移动成员时按当前世界几何释放，不重新触发自动适应而改变捕获尺寸。

跨选区连接不能跨表保持绑定。可见确认框说明源侧与移动侧将断开的端点数量：
源侧端点留在原位置，移动侧端点自由化后随对象平移。
仅明确选择“断开跨表连接并移动”才执行；取消及失效的旧回调均无文档变化。
锁定的外部连接线、不可定位端点或不可绘制资源导致整批拒绝，撤销恢复原绑定。

## 资源保真修复

独立文本框的详细主体填充、轮廓纹理资产原先漏入工作簿资产集合。
两条回归先在原实现失败，再将文本框与形状一起纳入既有收集入口。
隐藏组内纹理仍由原组消费者递归收集；不添加永久保留所有资源的旁路。

实际资产 URL 在复制、两表剪切和撤销后保持；内部保存重开仍能取得主体资产。
最后一个当前文档引用移除时，其 URL 正常回收，另一个已加载文档的 URL 不受影响。
历史所需的原资产沿现有存储生命周期保留。

## 边界

仅同一工作簿，不涉及其他工作簿或操作系统文件剪贴板。
继承组合共同三维场景或容器效果的成员不能单独提取，需移动完整所属组。
既有字体、文字变形、像素预算与原生工作簿交换限制继续适用。
