# 艺术字选区样式与局部文字效果 — 2026-10-13

## 当前片范围

同一套 25 个艺术字预设可用于对象、文字选区或光标处后续输入。文字编辑中的预设只替换
填充、轮廓、阴影、映像、发光五类外观；保留文字、字体、字号、B/I/U、框与变形及未选中字符。
选区混合状态与光标待输入状态使用不同说明，不用整对象改写代替局部样式。

- Core 只新增这三种局部效果字段。缺席继承、明确无、本地值严格区分并深复制，范围操作和历史保真。
  实际存在字段时内部快照使用 V72，包括明确无；字段缺席保持原特性版本，低版本载荷拒绝偷带字段。
- 真实所属字形子集生成效果，而非裁取整段合成像素。映像使用所属字符颜色及整段共同基线。
  内阴影不改变前景透明度，也不把轮廓盖写顺序变成按效果分组逐段叠加。
- 整对象重套、清除和单类外观广播清除对应局部覆盖；组与 owned leaf 从实际字符读回五类混合状态。
- 同一文字草稿保留局部格式、本地 Undo/Redo 与一次最终提交。光标预设仅影响后续输入，离位清除待输入格式。
- 真正格式窗格 pointer/click 不会被 Workspace 的外部动作捕获提前提交；豁免仅匹配当前文字会话。
  旧会话标记和真正外部动作仍按既有先应用规则执行，组合输入期间真实点击不提交半成品。
- 编辑面明确显示源文本预览提示；实际应用、透明命中和既有打印共用同一效果像素消费者。
  缺素材、原生字形失败、过大效果或实际工作/临时内存超预算时保留原数据并拒绝。

局部阴影已有桌面逐字符参考。局部映像、发光是明确的一致产品规则，未将未采到的逐字符桌面行为称为已实测。
当前局部这三类字段与活动独立文字 3D 格式/相机或非零文字柔化组合明确拒绝；主体共同场景另有既有消费者。
41 项文字转换范围不变，4 项沿路径仍仅支持可打印 ASCII 的独立刚性字形，不能泛称复杂脚本完整排版。
