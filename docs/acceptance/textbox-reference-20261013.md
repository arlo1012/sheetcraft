# 文本框单元格来源 — 2026-10-13

## 本片合同

普通文本框拥有独立的单单元格来源，不保存计算结果文字，不改为公式字符串或艺术字身份。
专用右键入口支持根对象和明确选中的组内叶，来源工作表选择与当前表单格选择器共用同一捕获实例。
替换已有内容有可见说明；解除链接保留当前显示文字。用户主动操作遵循对象权限。

显示使用当前计算周期、数字格式、条件格式、表格格式、日期系统和区域设置。
源字体与颜色留在源单元格。源刷新保持存储框与历史；用户明确格式操作才按当前结果执行原自动适应。
异常或超出文字预算时提示，不截断、不烘焙空白、不冒充成功。

来源结构更新先对整本工作簿预检，再维护本表及跨表、隐藏和嵌套的来源地址或删除标记。
合法的纯地址维护不受目的锁定对象阻断；严格证明之外的属性、身份、文字、格式或位置变更没有此豁免。
每个结构事务、绑定或解除的逆命令恢复准确来源，失败不产生部分单元格、尺寸、对象或历史写入。

内部快照74仅在实际具有来源字段时启用；无该字段仍保留实际旧协议，旧协议携带新字段拒绝。
现有复制、组合、画布与内部打印消费派生显示，真实编辑和逆投影继续使用原始空文字对象。
本片不改变工作簿原生交换能力。

## 当前边界

仅绝对单单元格链接，不接受范围、名称、表达式或外部工作簿。复制对象保原来源；复制整张来源表重映射内部自引用。
源刷新不自动适配存储框，来源对话框会说明这一点。显示超过100000个 UTF-16 单元或必要计算/字体/像素资源不可用时明确拒绝相关操作。
沿路径文字等高阶格式继续遵守现有脚本、字形与像素预算，不因动态来源另开低保真旁路。
