## 已实现

- 分类插入入口：图标、九类窗体控件、三类迷你图；图片入口区分单元格和浮动图片。
- 附件在提交前选择文件及文档/图标显示方式；超链接分别配置网页、工作表位置和邮件。
- 批量图片可排序、移除和选择横向/纵向排列；浮动图片另支持层叠。整批通过一次 Core 命令写入。
- 横向/纵向批量排列可指定每行/每列 1–100 张后换行/换列；单元格目标跨过合并区域，浮动图片依本组最大宽高留出间距。
- 截图支持拖动区域、数值输入和裁切；复用已有指针会话。
- 照相机依据可见行列尺寸计算初始比例；窗体切换类型时清理不适用的配置。
- 打印入口、选区打印、起止页码、预览缩放及页面设置往返；图标、照相机、附件、控件加入绘制和分页范围。
