## Reproduced interrupted callback defect and local fix

Two focused tests capture the actual Symbol component's owner callbacks, close
it, then deliver an old insert/close after cancellation or reopening. Before the
fix, the old insert starts a new editor draft after cancellation, and an old close
hides the newer dialog. These are unit-reproduced lifecycle defects; the browser
happy path by itself did not deliver obsolete callbacks.

The workspace now owns a keyed Symbol dialog identity. Each insert/close callback
is bound to that instance; insert also checks captured workbook generation,
sheet identity and address, then uses the existing busy/permission/editor-owner
checks. Dismissed/older callbacks are inert. Navigation still closes the dialog.
The existing selection transformation, parser, commit/history, custom field,
preset list and snapshot format are unchanged. No general dialog registry was
introduced. Final regression adds active sheet navigation before stale insertion.
